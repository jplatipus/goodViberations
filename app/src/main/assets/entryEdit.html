This page is used to add new fields and to set field value.

Save and Cancel

Once changes have been made to the entry's details, they can be saved: tap the Save button at the bottom of the page.

To reset the page to its original values, tap the Cancel button at the bottom of the page.

Changing a Value

To change a value, tap the field to change. Enter the new value, then tap Done at the top of the page to dismiss the keyboard.

After all the changes required have been entered, Save should be tapped to save the changes permanently.

Adding a Question and Answer

To add a new question and answer, the green plus (+) is tapped. This opens up a new page where a new question and answer can be entered.

After making changes, Save should be tapped to save the changes permanently.

Removing a Question and Answer

To remove a question and answer, the red (-) is tapped.

After making changes, Save should be tapped to save the changes permanently.

Changing a Question and Answer

To change a question and/or answer the gray sign >, to the right of the field, is tapped. The opens up a new page where both the question and answer can be changed.

After making changes, Save should be tapped to save the changes permanently.
