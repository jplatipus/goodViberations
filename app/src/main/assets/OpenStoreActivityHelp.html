To open a store:

  1. Enter the store's password in the password field
  2. Enter the store's memorabe date in the date field
  3. Dismiss the keyboard by tapping the "Done" button, or by dragging the screen down.
  4. Tap the List Entries button in the toolbar at the bottom of the screen

If the password and date are correct the next page appears.

If an error message is displayed, it usually means the password or date did not match the last password set for the store.

Important Note: the encrypted store is sync'd when the device is sync'd. Please keep a backup of the encrypted file. The file can be placed back using the sync operation. The filename is case sensitive, and has the name "info.jce"
