Class name: EditEntryFieldActivity
Title:Edit Field
Level: level six activity, displayed when a entry field has been selected for editing.

UI Specification

The title in the title bar displayed at the center, top of the activity is the entryName.
The title bar has a left arrow image button, called btnBack, on the left hand side of the title bar.
The arrow points left.

Initialisation

When the activity is initially displayed, if the given entryName is a blank or empty string, the following is carried out:

  1. A member variable called selectedListIndex is set to -1
  2. a new EntryData instance is created, called entryData.

When the activity is initially displayed, if the given entryName is not a blank or empty string, the following is carried out:

  1. A member variable called selectedListIndex is set to -1
  2. The method loadEntry in DataLayer is called, with the name parameter given as entryName. The returned value is saved in the variable entryData
  3. The selectedIndex parameter passed to this method is saved in the variable selectedListIndex. This is used to extract the field name and field value from the entryData object.
  4. txtFieldName is set to the field name.
  5. txtFieldValue is set to the field value.

Functionality

When the button btnBack is pressed, the activity is popped of the activity stack, and then the app navigates to EditEntryActivity.

When the btnExit is pressed, the activity is popped of the activity stack (two parent activities also need to be popped off the activity stack), and then the app navigates to MainActivity

When the btnHelp button is pressed, the activity navigates to the HelpActivity, requesting that the asset file EditEntryField.html be displayed.

When the btnSave button is pressed, the activity:

  1. Updates the entryData object with the current values from the UI widgets.
  2. Calls the saveEntry method in DataLayer, passing the entryData object.
  3. The activity is popped off the activity stack, and then the app navigates to the EditEntryActivity. The value of is passed to the parameter entryDataParameter EditEntryActivity.
