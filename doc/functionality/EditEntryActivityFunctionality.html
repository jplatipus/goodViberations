Class name: EditEntryActivity
Title:Edit Entry
Level: level five activity, displayed when there is an existing store.

The activity is displayed when an entry is created.
This activity is also displayed when an existing entry is displayed in the ViewEntryActivity and the edit button is pressed.
The entryName is supplied to the EditEntryActivity.

The arrow points left.

The activity has a vertically scrolling list of rows. Each row has a text field and an image button to the far right of the row. The image is of an arrow head pointing right. The scrolling list is saved in the variable vlsFields

Initialisation

When the activity is initially displayed, if the given entryName is a blank or empty string, the following is carried out:

  1. A member variable called selectedListIndex is set to -1
  2. a new EntryData instance is created, called entryData.

When the activity is initially displayed, if the given entryName is not a blank or empty string, the following is carried out:

  1. A member variable called selectedListIndex is set to -1
  2. The method loadEntry in DataLayer is called, with the name parameter given as entryName. The returned value is saved in the variable entryData

The display's widget contents are initialised:

  1. A new row in the vlsFields list is created for the entryData name member variable.
  2. A new row in the vlsFields list is created for the entryData creationDateTime member variable.
  3. A new row in the vlsFields list is created for the entryData lastModifiedDateTime member variable.
  4. A new row in the vlsFields list is created for the entryData password member variable.
  5. For each field in the entryData detailFields list, a new row in the vlsFields list is created.
  6. A new row in the vlsFields list is created for the entryData notes member variable The notes text field should be large enough to contain the entire notes multiline text

EditEntryActivity functionality

Post initialisation activity functionality

When a row in the vlsFields list is selected, the followimg is carried out:

  1. selectedListIndex member variable is set to the selected index of this row.
  2. The textfield in the row is enabled.
  3. The textfield gains input focus.
  4. The text cursor appears in the textfield.

When the image button in the row is pressed, the following is carried out:

  1. selectedListIndex member variable is set to the selected index of this row.
  2. The app navigates to EditEntryFieldActivity. The selected entryName and the selectedListIndex member variable are passed to the activity EditEntryFieldActivity

When the button btnBack is pressed, the activity is popped of the activity stack, and then the app navigates to ListEntriesActivity.

When the btnExit is pressed, the activity is popped of the activity stack (two parent activities also need to be popped off the activity stack), and then the app navigates to MainActivity

When the btnHelp button is pressed, the activity navigates to the HelpActivity, requesting that the asset file entryEdit.html be displayed.

When the btnSave button is pressed, the activity:

  1. Updates the entryData object with the current values from the UI widgets.
  2. Calls the saveEntry method in DataLayer, passing the entryData object.
  3. the activity is popped of the activity stack, the activity navigates to the ViewEntryActivity. The value of entryName is passed to the ViewEntryActivity.

When the btnAddField button is pressed, the activity

  1. selectedListIndex member variable is set -1.
  2. The app navigates to EditEntryFieldActivity.
